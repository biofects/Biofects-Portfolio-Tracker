# Biofects Portfolio Tracker

A Home Assistant integration for tracking investment portfolios with real-time stock and cryptocurrency prices.

## Installation

See the [main README](../../README.md) for detailed installation and configuration instructions.

## Features

- Real-time stock tracking via Finnhub API
- Cryptocurrency tracking via CoinGecko API  
- Portfolio performance analytics
- Financial news integration
- Efficient batch API calls
- Smart caching system
- Easy UI configuration

## Quick Start

1. Install via HACS or manually
2. Add integration through Home Assistant UI
3. Enter your API keys
4. Add your holdings
5. View sensors in your dashboard

For detailed documentation, examples, and troubleshooting, see the [full README](../../README.md).
